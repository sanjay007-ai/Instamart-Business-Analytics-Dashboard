# 📊 Instamart Business Analytics Dashboard — Power BI

An interactive **11-page Power BI Business Analytics Dashboard** built on a quick-commerce **sample dataset** (5,000 orders, 1,800 customers, Apr 2025 – Mar 2026). It analyzes sales, revenue, profit, customers, orders, products, regional performance, discounts, delivery operations, targets, and overall business performance across India.

This project demonstrates an end-to-end **Data Analyst / Business Intelligence workflow**, from data preparation and transformation to data modeling, DAX analysis, interactive visualization, and business insights.

## 💡 Key Insights

- **North** is the top region with **₹509K sales (25.98%)** and the highest profit (**₹136K**).
- **North and South together** contribute over **50% of total sales**.
- **Central** is the growth opportunity, with only **9.35%** of total sales.
- **Diapers** is the top-selling product (**₹94.5K**), followed by **Baby Wipes** (**₹92.6K**).
- **Madhya Pradesh** has a high cancellation rate (**6.98%** vs the **4.20%** average), so it is worth investigating.
- **UPI** is the most used payment method (**2,367** of 5,000 orders).
- Average delivery time is similar across regions (about **24 to 25 minutes**), with a **4.10** average customer rating.
- The business achieved **130.63%** of its **₹1.50M** sales target.

- Reviewed source datasets and column structures
- Prepared order, customer, product, and store data
- Checked data types and required fields
- Cleaned and transformed data using Power Query
- Prepared fields for sales, discounts, costs, and profit
- Organized data for customer, product, regional, and operational analysis

The prepared data was used to build the data model and create the Power BI reports.

# 📐 Data Modeling

The project uses four main tables to support business analysis.

| Table | Description |
|---|---|
| **Orders** | Transaction-level sales, discounts, costs, profit, delivery, and order status |
| **Customers** | Customer attributes and customer-level analysis |
| **Products** | Product and category analysis |
| **Stores** | Geographic and regional analysis |

Relationships between these tables support analysis across customers, products, stores, and orders.

# 🚀 How to View

1. Scroll up to see all 11 dashboard pages as images, or open any `.png` file in this repository.
2. Download the Power BI `.pbix` file from this repository.
3. Open the file using **Power BI Desktop**.
4. If prompted for the data source, click **Transform data → Data source settings** and select `Instamart_Sales_Data.xlsx` from this repository.
5. Refresh the data if necessary.
6. Explore the dashboard pages, filters, KPIs, and visualizations.
